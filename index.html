Software Engineering

What is Software Engineering?

Software Engineering is the systematic application of engineering principles to creating software that is not just beautiful but also reliable, efficient and maintainable.

01 · The discipline

SWE is not just about coding it involves:

Understanding the problem⇒ Design⇒ Implement⇒ Test⇒ Deploy⇒ Observe and maintain

02 · Workflow

A Practical Engineering Workflow

  1. Clarify the user need and define what “done” means.
  2. Break the problem into small, testable tasks.
  3. Design the simplest suitable solution.
  4. Implement and verify one small change at a time.
  5. Use Git, code review, tests, and documentation to protect quality.
  6. Deploy, observe real usage, fix problems, and improve.

Programming Concepts

Concepts likely to be found in every programming langauge. They are foundations to mastering programming.

06 · Foundations

Programming Concepts

  1. Variables: A strorage location in a memory with a name used to hold data
  2. Data Types: classification of data term, that define operation sthat can be carried out on it. E.g Number, strings, bigInt, Object,
  3. Control Structures: The order of execution of statements in a program
    1. Conditional statements: if, else, switch.
    2. Loops: for, while, do-while.
    3. Branching: break, continue, return
  4. Functions (or Methods): is used to perform a particular task that can be reusable throughout the program

06 · Foundations

Programming Concepts

  1. Data Structures: A way of organizing and storing data for easy access and modification. Examples are Trees, Stacks, Queues e.t.c
  2. Algorithms: Pre-written mechanisms for solving a problem. Examples bubble sort, Quick sort, sorting e.t.c
  3. Big O notation: A way to measure how difficult/complex a program is in terms of Time and Space
    1. Time Complexity: How long it takes
    2. Space Complexity: The space or memory it takes

When a person enters a URL in a browser (the client), The client asks for the IP Address, through the DNS - Domain Name System and gives the IP to the server as a request and the server returns with a response in tiny packets in HTML, CSS and JS and displays it in the browser.
